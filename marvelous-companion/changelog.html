Changelog

Marvelous Companion

0.1.9

September 2026 · Internal Testing (Android & iOS)

  • Game sets now include a Locations tab — browse each set’s locations with a full-screen image viewer
  • Stretch goal cards for Marvel Seasons 1–3 are now split out into their own Stretch Goals sets instead of being bundled into the Core sets
  • New gold variant cards for Batman and Superman
  • Manage Collection now groups game sets by season with a select-all / deselect-all option per season
  • Fixed owned/collected status sometimes not persisting when switching between screens
  • Various accessibility improvements for screen readers
  • Corrected Superman and Wonder Woman card data, plus verified and corrected Season 1 villain master plan and threat cards

0.1.8

September 2026 · Internal Testing (Android & iOS)

  • Villain cards now sort consistently in the deck view
  • Villain master plan cards now show a movement icon with count
  • You can now mark an individual character as owned or unowned independently of its game set
  • Hero action icons reordered to match the physical cards; “emphasis” card wording now highlighted on hero and villain cards
  • Fixed Marvel (Ares) master plan card data
  • Fixed a crash on launch after updating from an old version

0.1.7

August 2026 · Internal Testing (Android & iOS)

  • Duplicate hero and villain master plan cards now collapse into a single entry with a “×N” copies badge
  • Hero cards now sort consistently in the deck view
  • New Glossary filters: Types, Ownership (including an “unowned” option), Kickstarter-exclusive, and Unreleased content
  • New A-Z / Z-A sort toggle for the Glossary list
  • Fixed DC game sets that weren’t displaying correctly
  • Fixed unreleased game sets incorrectly showing up in Manage Collection settings

0.1.6

August 2026 · Internal Testing (Android & iOS)

  • First step toward collection tracking — mark game sets as owned and filter your list down to just what you have
  • Game set and character details screens now show whether you own that set (characters inherit ownership from their set)
  • New Settings screen gathers app-wide options in one place, including a shortcut to mark everything as owned at once
  • Fixed hero cards that had attack and movement action icons swapped
  • Fixed Domino’s Probability Manipulation card text
  • Fixed dual characters occasionally showing the wrong name on their villain side
  • Fixed the unreleased badge squishing other icons in the list
  • Fixed repeatedly tapping the same tab occasionally breaking navigation
  • Fixed long set names wrapping awkwardly in the details screen header

0.1.5

July 2026 · Internal Testing (Android & iOS)

  • Figures and their decks are now combined into a single Character view — browse a character and its cards in one place
  • Game sets now show their characters as a row of tappable cards that jump straight to each character’s details
  • Team characters (like A-Force) list their members the same way
  • Clearer filtering with a labeled chip that defaults to Characters
  • Redesigned details screen — all stats now live in a single card, set and season moved into a header pill, and tidier spacing
  • Fixed Hulkling’s missing Impersonating sidebar card, corrected villain cards for some dual characters, and cleaned up stray card data

0.1.4

July 2026 · Internal Testing (Android & iOS)

  • Batman Hush is now available, with new heroes, villains, and cards to explore
  • Hero card abilities now show action icons instead of spelled-out text, matching the physical cards
  • General text and formatting cleanup across hero cards
  • Fix software keyboard not showing when searching

0.1.3

July 2026 · Internal Testing (Android & iOS)

  • Brand new app icon
  • Refreshed design for the details screen, including an improved toggle for dual characters
  • Smoother, more predictable back gestures on newer Android versions
  • Under-the-hood updates to keep the app fast and current on the latest Android and iOS

0.1.2

July 2026 · Internal Testing (Android & iOS)

  • Marvelous Companion is now available on iOS via TestFlight, with the same features as the Android version
  • About screen now displays the current app version
  • New feedback button — tapping it copies your version to clipboard and opens the feedback form
  • Support email is now a tappable link on the About screen

  • Added app launcher icon
  • Updated support contact to support@punkforge.dev
